# custom style

fugleramme custom artwork style, bind-mounted read-only into the fugleramme container.
Filled by tools/plates (see docs/claude-code-prompts.md, session 3). Select "custom" at :8080/admin.
Files: birds/<genus>-<species>.webp, manifest.json, ATTRIBUTION.md. perches/ may stay empty; fugleramme falls back to classic perches.
